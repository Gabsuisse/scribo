Ce que le système va lire

Le titulaire, l'IBAN, le BIC et la domiciliation. Le code banque, le code guichet, le numéro de compte et la clé RIB sont ensuite recalculés à partir de l'IBAN, ils ne sont pas devinés.

Formats acceptés

  • PDF
  • PNG
  • JPG
  • WEBP

Un PDF avec texte est lu directement. Une image ou un PDF scanné passe par la reconnaissance de caractères, c'est plus lent.
