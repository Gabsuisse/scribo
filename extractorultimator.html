L'extraction qui n'a besoin de la confiance de personne.

Extraction d'informations depuis un document, en local, avec Mistral 7B. Déposez un document, récupérez un JSON propre et prêt à pré-remplir un formulaire. Le modèle tourne sur votre ordinateur, chaque valeur est recontrôlée par des règles de calcul avant de vous être montrée.

Projet créé par Gabriel Danet pour la souveraineté numérique : LinkedIn

Relevé d'identité bancaire

Ce que le système va lire

Le titulaire, l'IBAN, le BIC et la domiciliation. Le code banque, le code guichet, le numéro de compte et la clé RIB sont ensuite recalculés à partir de l'IBAN, ils ne sont pas devinés.

Formats acceptés

  • PDF
  • PNG
  • JPG
  • WEBP

Un PDF avec texte est lu directement. Une image ou un PDF scanné passe par la reconnaissance de caractères, c'est plus lent.

Le pourcentage n'est pas déclaré par le modèle, il est calculé ici : 50 % de base, +30 si la valeur se retrouve telle quelle dans le texte source, +20 si elle passe son contrôle de forme (clé mod-97 pour l'IBAN, format pour le BIC). Les champs sous 80 % méritent un coup d'œil avant d'être injectés dans un formulaire.
